# Contrast matrix

Generated by `design/tokens/build-tokens.mjs`. Do not edit by hand. The pair list lives in `tokens.json` under `$extensions.grapho.pairs`; the build fails if any graded pair misses its requirement in any variant.

## Requirements

| Requirement | Ratio | Applies to |
|---|---|---|
| text | 4.5:1 | Text and icons carrying meaning, at any size |
| large | 3:1 | Large text (18.66 px bold or 24 px) |
| ui | 3:1 | Edges, rings, indicators and fills that identify a component or its state (WCAG 1.4.11) |
| number | as stated | Ink on the page is 7:1 |
| exempt | none | Computed and shown, with a reason |

Alpha colours are composited over the host surface in gamma encoded sRGB, rounded the way the browser rounds. A pair "over" a host is graded on every host in its list. `any` pairs pass when one colour of the pair reaches the ratio (the two-tone focus ring and handle).
